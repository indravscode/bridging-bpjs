# Kebijakan Keamanan

## Melaporkan kerentanan

Jika menemukan kerentanan keamanan, laporkan secara privat melalui email ke [gdindra13@gmail.com](mailto:gdindra13@gmail.com). Sertakan versi package, penjelasan masalah, dan langkah reproduksi.

Gunakan data dummy dan jangan sertakan kredensial BPJS atau data pasien. Hindari mengungkap detail kerentanan di issue publik sebelum berkoordinasi dengan maintainer.

Untuk bug biasa atau saran perbaikan, silakan buat [issue](https://github.com/indravscode/bridging-bpjs/issues) atau [pull request](https://github.com/indravscode/bridging-bpjs/pulls).
